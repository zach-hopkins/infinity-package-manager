# Personal EET adventure

`modpack.yaml` is the current-release equivalent of the supplied, deduplicated
WeiDU log. It selects the same named gameplay choices while preserving the
portable IEPM boundary: local game paths and measured fingerprints are not
stored in the file.

It resolves against the bundled registry with WeiDU 25100. The large SCS and
Tweaks selections are structurally mapped and executable-preflight-ready, but
the combined configuration remains **Untested** under IEPM's public support
policy until it completes a clean disposable build and launch/gameplay smoke.

To use it in the desktop app, choose this `modpack.yaml`, select clean BG:EE
and BG2:EE source installations, and let IEPM create the disposable workspace.
Do not point it at an already-modded or only game installation.
